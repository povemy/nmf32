API Gateway URL

For most of the Razorpay Curlec APIs, the Gateway URL is https://api.razorpay.com/v1. You need to include this before each API endpoint to make API calls. However, certain APIs are on V2. Hence, the gateway URL may differ for certain APIs.

Example

Use the URL https://api.razorpay.com/v1/payments to access payment resources.
