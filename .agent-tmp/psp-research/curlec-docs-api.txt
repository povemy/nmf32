[]Copy pageCopy page

Get started with Razorpay Curlec APIs and test them on Postman. Generate API Keys in Test and Live Modes.

[]Copy pageCopy page

[]

Available in🇮🇳 India🇲🇾 Malaysia🇸🇬 Singapore🇺🇸 United States

Razorpay Curlec APIs are completely RESTful, and all our responses are returned in JSON.

[]

Integrations

-   Looking to integrate your website, ecommerce store or mobile app with Razorpay Curlec Payment Gateway? Find the right integration method.
-   Accept payments without a website or app using other Razorpay Curlec products, such as Payment Links, Payment Pages and Invoices.

​

[]

API Gateway URL

For most of the Razorpay Curlec APIs, the Gateway URL is https://api.razorpay.com/v1. You need to include this before each API endpoint to make API calls. However, certain APIs are on V2. Hence, the gateway URL may differ for certain APIs.

[]

Example

Use the URL https://api.razorpay.com/v1/payments to access payment resources.
