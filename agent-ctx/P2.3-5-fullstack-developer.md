## State machine (WebhookDelivery.status — existing columns only)

```
pending ──real 2xx──▶ success  (TERMINAL; never re-attempted/overwritten)
pending ──non-2xx / network error──▶ pending (retry per derived schedule)
pending ──attempt 8 completed──▶ failed (TERMINAL, lastError in attempt log)
pending ──SSRF/URL refusal (permanent)──▶ failed (immediate, no 41h pointless retry)
pending ──event unsubscribed / endpoint row gone──▶ failed (no HTTP attempt, attemptNo 0 log)
pending ──older than 7 days (stale hygiene)──▶ failed
failed  ──admin replay (force claim)──▶ pending → real attempt again
```

Retry schedule (derived, NO nextAttemptAt column — deliberate, see migration note):
inline attempt 1, then 1m → 5m → 15m → 1h → 4h → 12h → 24h (8 attempts, ≈41.4h).
`nextRetryAt = lastAttemptAt + backoff[attempts]`; never-attempted rows due immediately.
Idempotency: atomic conditional claim (`status:"pending"` + `lastAttemptAt null OR ≤
now-60s`, `attempts:{increment:1}`, `lastAttemptAt:now`) BEFORE the HTTP call; racing
claimers get count 0 → skip. Final write conditional on own claim (attempts==attemptNo,
status still pending).

## Signing + receiver contract

Headers: `content-type: application/json`, `user-agent: SHOPMESH-Webhooks/1.0`,
`x-nomofee-event`, `x-nomofee-timestamp` (unix seconds), `x-nomofee-signature` =
lowercase hex HMAC-SHA256(secret, `${timestamp}.${rawBody}`). Timestamp is INSIDE the
signed material → cannot be refreshed without invalidating the signature (replay guard);
documented ±10 min receiver tolerance. Signature header OMITTED when endpoint has no
secret (unsigned — receiver should treat as unauthenticated notification). Contract
documented in lib header, cron GET, seller UI; `verifyWebhookSignature` is the reference
implementation (timing-safe compare).

## SSRF guards

All outbound POSTs go through `safeRequestJson` (src/lib/safe-fetch.ts): scheme
http/https only, no userinfo, private/reserved/metadata IP literals refused (IPv4+IPv6,
mapped/NAT64 unmapped), DNS resolution guarded per hop (rebinding/TOCTOU-closed via
pinned undici dispatcher), manual redirects (≤3) re-validated per hop, 10s timeout,
bounded (2KB) diagnostic body capture. SSRF/URL refusals classified PERMANENT → delivery
fails immediately (honest attempts count); timeouts/network errors stay retryable.

## Success is only ever real

`finalStatus = "success"` is assigned exclusively when `res.ok && res.status >= 200 &&
res.status < 300` from a real HTTP response; non-2xx codes and network/SSRF refusals are
recorded verbatim (responseCode / error). No code path writes success without a response.
