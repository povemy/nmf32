   727→// LATE-PAYMENT RECONCILIATION (mission: final operational gaps, Phase 2).
   728→// A payment.succeeded webhook that arrives AFTER the expiry sweep released the
   729→// group's stock is refused with 409 GROUP_EXPIRED (money never enters the
   730→// ledger). For a REAL PSP the buyer's funds are already captured at the
   731→// provider — this table is the durable, traceable REFUND OBLIGATION for those
   732→// funds: who must be refunded, how much (the webhook amount = captured funds),
   733→// and where the provider interaction stands. It is an obligation tracker, NOT
   734→// a ledger posting — ledger postings remain exclusively under claim-first
   735→// payment success. Duplicate webhooks converge on ONE row per (provider, ref)
   736→// via the unique key; retries can never duplicate the obligation.
   737→model PaymentReconciliation {
   738→  id                String    @id @default(cuid())
   739→  provider          String
   740→  // PaymentGroup.ref — the PSP checkout session the late payment belongs to.
   741→  providerRef       String
   742→  // PSP's own payment object id when the event carries one (real adapters
   743→  // MUST send it; the mock rails identify by providerRef).
   744→  providerPaymentId String?
   745→  // Amount captured at the provider per the verified webhook (this is what
   746→  // must be RETURNED — not the group total when they diverge; divergence is
   747→  // recorded in resolutionNote for operator verification).
   748→  amountMinor       Int
   749→  currency          String    @default("MYR")
   750→  reason            String    @default("late_payment_after_expiry")
   751→  // requested   — obligation recorded, no successful provider attempt yet
   752→  // processing   — attempt in flight (durable intent written pre-call)
   753→  // succeeded    — refund confirmed FROM the provider's authoritative record
   754→  // failed       — provider REJECTED the refund (permanent; operator item)
   755→  // unknown      — provider outcome pending/timed out (re-checked next tick)
   756→  status            String    @default("requested")
   757→  providerRefundId  String?
   758→  attempts          Int       @default(0)
   759→  lastAttemptAt     DateTime?
   760→  lastError         String?
   761→  resolutionNote    String?
   762→  createdAt         DateTime  @default(now())
   763→  updatedAt         DateTime  @updatedAt
   764→
   765→  @@unique([provider, providerRef])
   766→  @@index([status])
   767→  @@index([updatedAt])
   768→}
