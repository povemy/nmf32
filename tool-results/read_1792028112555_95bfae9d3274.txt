   545→// OPTION B — one PSP checkout session: the buyer pays ONCE for a checkout
   546→// that may span N seller orders. A licensed PSP collects the single charge,
   547→// deducts the platform's application fee (commission) and settles each
   548→// seller their share — SHOPMESH never custodies the funds; the ledger +
   549→// seller wallet mirror the PSP's per-seller balances (see src/lib/psp.ts).
   550→// Each member Order is fulfilled/paid-out per seller (commission → ledger →
   551→// wallet → payout), exactly like a single-order payment.
   552→// (First built as "Option A" collect-then-disburse; identical data model.)

   558→  provider      String // fpx_toyyibpay | fpx_curlec | tng | grabpay | card_stripe
   559→  status        String       @default("requires_payment") // requires_payment | succeeded | failed | expired
   560→  currency      String       @default("MYR")

   562→  discountMinor Int          @default(0)
