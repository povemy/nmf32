    98→    98→/// Phase 1 (C4): TOTP MFA enrollment for administrators.
    99→    99→/// `secretEnc` = AES-256-GCM (iv:tag:ciphertext, base64 segments) encrypted
   100→   100→/// with MFA_ENCRYPTION_KEY. `recoveryHashes` = JSON array of sha256(code)
   101→   101→/// hex digests - one-time-use recovery codes, never stored in plaintext.
   102→   102→/// `confirmedAt` null = enrollment started but not yet verified by a valid
   103→   103→/// TOTP code; login enforcement only applies once confirmed.

   105→   105→/// recently ACCEPTED code — CAS-guarded monotonic update rejects any code

   177→   177→// FINAL CLOSURE (guest-order OTP + shopper email verification) — ONE challenge
   178→   178→// table serves both purposes (no column was added to ShopperUser/Order on
   179→   179→// purpose: a missing column would break every existing query pre-migration,
   180→   180→// while a missing TABLE is tolerated fail-closed via the P2021 guard, exactly
   181→   181→// like AdminMfaEnrollment):
   182→   182→//   purpose "guest-order"   → subjectId = Order.id. Successful verify DELETES
   183→   183→//     the row (CAS) — the issued order-access grant is the artifact. The
   184→   184→//     knowledge pair (email + NM- order number) can now only REQUEST this
   185→   185→//     challenge; it no longer authorizes any order data.
   186→   186→//   purpose "shopper-email" → subjectId = ShopperUser.id. Row PERSISTS with
   187→   187→//     verifiedAt set — the durable proof of email ownership that gates
   188→   188→//     guest-order claiming in claimGuestStateForShopper().
   189→   189→// Codes are stored ONLY as HMAC-SHA256(EMAIL_OTP_SECRET, "otp:v1:" + purpose +
   190→   190→// ":" + subjectId + ":" + utcDayBucket + ":" + code) — never plaintext, never
   191→   191→// logged. `attempts` survives re-issuance while a row is unexpired (repeated
   192→   192→// issuance cannot reset brute-force accounting); it resets only after expiry.
   193→   193→// No FK on purpose/subjectId: the subject is polymorphic by design.
   194→   194→model EmailOtpChallenge {
   195→   195→  id         String    @id @default(cuid())
   196→   196→  purpose    String
   197→   197→  subjectId  String
   198→   198→  codeHash   String
   199→   199→  attempts   Int       @default(0)
   200→   200→  expiresAt  DateTime
   201→   201→  verifiedAt DateTime?
   202→   202→  createdAt  DateTime  @default(now())
   203→   203→  updatedAt  DateTime  @updatedAt
   204→   204→
   205→   205→  @@unique([purpose, subjectId])
   206→   206→}
